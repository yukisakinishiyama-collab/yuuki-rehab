## 3. 事前に知っておくべき制約（重要）

### ⚠️ Instagramは未接続です
Meta連携が未完のため、**Instagramを選んで予約しても自動投稿されません**。
時刻が来ると「**手動投稿が必要（action_required）**」という状態で止まります。
その場合は本文をコピーして、Instagramアプリから院長が手動投稿する運用になります。
→ これは想定内の動作です。エラーではありません。

### ⚠️ 未デプロイの変更があります
ローカルに未pushのコミットが9件あります（権限分けなど）。
本番はまだ**単一パスワード**で動作しています。院長が `git push origin main` を
実行すると、以降は「院長=管理者／スタッフ=編集」の権限分けが有効になり、
**予約・公開の操作は管理者パスワードでログインした場合のみ**可能になります。

### 予約の実行タイミング
GitHub Actions が15分ごとに実行エンドポイントを叩き、時刻が来た予約を処理します
（Vercelの日次cronは予備）。分単位ぴったりではなく、最大15分程度の遅れが出ます。

## 5. 医療広告ガイドライン：使ってはいけない表現

以下はアプリのチェッカーが自動で弾きます。**文章を編集・追記する場合は絶対に使わないでください。**

完全治癒／必ず治る／絶対に治る／1回で治る／地域No.1／どこよりも／最高の技術／
奇跡／副作用はありません／誰でも治る／効果を保証／満足度◯%／芸能人・プロ選手が来院／
永久に・二度と痛まない／他院では治らない／無痛／医師も知らない／成功率◯%／
ビフォーアフター・施術前後の写真／痛みが消える・なくなる／即効／治した・治します／
根本治療・根本改善／患者様の声・体験談／みなさんが改善／口コミで評判

**代わりに使う表現**：「改善を目指す」「軽減が期待できる」「状態に合わせた」
「〜と考えられています」「個人差があります」

用意済みの本文（§6）は**すべてチェック済み（6/6 pass）**です。そのまま使う分には問題ありません。
