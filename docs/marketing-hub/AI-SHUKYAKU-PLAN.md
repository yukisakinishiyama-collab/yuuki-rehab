# AI集客システム：いまの状態と実装計画（2026-11-04）

もとの指示書：「ゆうき整骨院 AI自動集客システム構築指示書」（2026-11-04）。
既存のコード・保存先・連携を調べたうえで、指示書の項目ごとに「できている／一部／まだ／外の設定待ち」を整理し、段階ごとの計画にした。

## 調べて分かった前提

- 集客は院内アプリの `/marketing/**`（Next.js・TypeScript・Tailwind）。保存先は Supabase の KV（`marketing_line_contacts` を `job:`・`analytics:` などの頭つきキーで共用。`kv-store-server.ts`）。
  新しいテーブルを作るには院長が Supabase の画面で SQL を実行する必要があるため、指示書の「推奨テーブル」は**同じ KV に頭つきキーで置く**（下の表）。データが増えたらテーブルへ移せる形にしてある。
- 予約の正本は GAS の予約システム。集客側は `?api=hubstats` で**個人を特定しない集計の行**（受付日・予約日・流入元・計測名・初めて/2回目以降・状態）だけを受け取る。二重の予約システムは作らない。
- ホームページ（shimonoseki-yuuki.com・Netlify。このリポジトリの外）の予約ボタン4か所は、すでに `/api/marketing/go?d=reserve&source=website&campaign=hp-…` を通っていて、押した数と予約の流入元が分かる。
  ホームページの **LINE ボタンは lin.ee へ直接**で、押した数は数えられていない。GA4・Search Console のタグはページに見当たらない。
- 公式LINE の 2 つの短縮URL（指示書の `lin.ee/88JzHyp` と、院内アプリで使っている `lin.ee/uaGKbfk`）は、どちらも同じアカウント（`@432amljv`）へ行く。変更は不要。
- 院長／スタッフは Basic 認証のパスワードで分かれる（`proxy.ts`）。経営の数字は隠しコマンドで開く「経営」と、院長だけが呼べる API に限っている。

## 段階の計画

### 第1段階（今回の PR）
- 集客を4タブに整理（上の表）
- 集客概要：未取得を 0 にしない表示、期間・分母・重複の数え方の明示
- 問い合わせ：状態の管理（スタッフも使える）。院長・スタッフの変更は監査ログへ
- 自動化設定：予約確認の通知と LINE の自動案内に「止める／テスト／動かす」。院長だけが変えられる。動いた記録を残す
- LINE：ブロックの記録、3択の案内（切り替え式）、通数と上限の表示
- 残り：GA4・Search Console の接続（院長の設定のあと）

### 第2段階：予約改善
- 同意の記録（marketing_consents）→ 前日リマインド（同意のある方へ1回。変更・キャンセル済みは送らない）
- キャンセル待ちの登録と通知（同じ枠に重複して送らない・先着の扱い）
- 本人が押せる配信停止ボタン
- 予約システム（GAS）側：無断キャンセルの区別と「新患の次回予約」の件数を集計に足す

### 第3段階：コンテンツ支援
- Google 投稿の下書き（重点テーマ：下関・彦島、足関節捻挫、成長期のスポーツ障害、ACL・半月板術後、股関節術後、バレエ・ダンス）
- Instagram リール台本（30〜60秒・テロップ・キャプション・ハッシュタグ）を週2本
- ホームページの記事案（同じ内容のページを量産しない。医学的に確かめられるものだけ）
- Search Console のキーワードからページ改善案

### 第4段階：AI最適化
- 日ごとの集計の控えと週次の集客レポート（因果を断定しない書き方）
- 広告費の入力と CPA
- 配信の頻度の調整

## 院長にお願いすること（外の設定）

1. **GA4 と Search Console**：ホームページ（Netlify）に GA4 のタグを入れ、Search Console にサイトを登録。接続用のサービスアカウントに閲覧権限を付ける（手順は接続のときに用意する）
2. **ホームページの LINE ボタン**：`https://lin.ee/uaGKbfk` を、計測つきの
   `https://yuuki-rehab.vercel.app/api/marketing/go?d=line&source=website&campaign=hp-line-<ページ名>` に差し替える（押した数が集客概要に出る）
3. **Google ビジネスプロフィール**：`GOOGLE-BUSINESS-SETUP.md` の「Googleとつなぐ」
4. **LINE の3択の案内**：自動化設定で LINE の自動案内を「テスト」・選択肢を「3つ」にし、院長の LINE から送って流れを確かめてから「動かす」に戻す（テスト中は、ほかの方への自動の案内が止まり、スタッフの返信待ちになる）
