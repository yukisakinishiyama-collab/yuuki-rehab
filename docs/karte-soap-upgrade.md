# カルテ（SOAP）を良くする計画 — Claude と Codex の分担

院長の依頼（2026-11-07）: SOAPカルテの質を上げる。関節ごとに本物に近い解剖図で部位を選べるように。初診は SOAP、経過はメモに書いている現状を直し、負傷部位や痛みの場所が変わっても追えるように。両方の AI で補い合って最高のものに。

## 分担

| 誰 | 何 |
|---|---|
| **Codex** | 解剖図のイラストと座標データ（`docs/anatomy-illustrations-brief.md`）。関節ごとに PR |
| **Claude** | アプリ側の土台と画面（下の段階1〜3）。院長の確認を取ってから本番へ |
| **院長** | 各段階の確認・承認。図の見た目と部位の妥当性の最終判断 |

お互いの作業がぶつからないように:
- Codex は `public/anatomy/**`、`src/lib/anatomy/zones/*.json`、`src/lib/anatomy/index.ts` の import 行だけを触る
- Claude は画面側（`src/components/rehab-management/**`、`src/lib/karte/**`、型）を触る
- 部位ID（`JOINT_ZONES`）はカルテの保存値。どちらも増減しない（増やすときは院長に確認して両方で合わせる）

## 段階

### 段階1（済・この PR）: 土台と依頼書
- `src/lib/anatomy/`（型・読み込み・検査スクリプト）、`AnatomyMap.tsx`（向きの切り替え・左右反転・部位の名札）。図が無い関節は従来の `JointDetailMap` に自動で戻る
- 問診票・評価の「関節別詳細部位」は `AnatomyMap` 経由に差し替え済み
- Codex への依頼書 `docs/anatomy-illustrations-brief.md`

### 段階2（済・PR）: 経過（2回目以降）の記入
- SOAP 入力に「初診」「経過」の切り替え。経過は前回のカルテから部位・NRS・施術・自宅運動・目標を引き継ぎ、変わったところだけ直す
- 部位（ComplaintEntry）に状態（経過中／軽快・終了）と開始日・終了日。終了した部位は引き継がない。「新しいケガ」を足せる
- 主な部位・傷病名が変わったら、カルテの表紙（Patient.bodyRegion / diagnosisLabel）も更新するか聞く
- 部位の移り変わり（いつ始まり、いつ終わったか）を来院カレンダーの下に一覧で出す
- SOAP の S/O に `AnatomyMap` を入れる（今日の痛みの場所・施術した部位を図で）… 段階3で、図の納品に合わせて

### 段階3: 質
- 前回との比較（NRS・ROM・テスト結果の推移を SOAP の上に小さく）
- 傷病名ごとの O/A/P のひな形（ACL 術後、半月板、オスグッド…）。院長が直して保存
- 所見の構造化（ROM・MMT は数値欄に、テストは既存のピッカー）
- まとめ行の自動生成（AI 相談と同じく個人情報を除いた要約から。院長が直してから保存）
