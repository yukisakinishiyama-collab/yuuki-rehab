# 画像所見レポート（参考意見）の作り方

あなたは、柔道整復師の施術方針決定を補助する**二次読影**を行います。このフォルダには、患者さんのCDから読み込んだ
DICOM原画像（氏名・ID・日付は取り除いてある）が入っています。全スライスを読み、`out/report.json` を書いてください。
PDF（A4）への組み立てと、氏名などの見出し・免責の文は、読影プログラムが行います。

- 読むもの: `case.md`（年齢・性別・主訴・確認したいこと・シリーズ一覧）
- 道具: `python rt.py <コマンド>`（`python rt.py -h` で一覧）。画像は `views/` に出るので Read で開く
- 書くもの: `out/report.json`（下の形）、図の指定 `out/figN.json`（`python rt.py figure out/figN.json` で `figures/figN.jpg` ができる）
- このフォルダの外は読まない・書かない。ネットにはつながない

## 1. 進め方

1. `case.md` を読み、`python rt.py list` で各シリーズの条件・画面の向き・番号の向きを確かめる
2. **左右と向きを確定する**（§2）
3. **全スライスを見る**: 各シリーズを `python rt.py montage <S>` で1回ずつ開く（X線は `view`）。気になる所を書き出す
4. **主訴の部位・確認したいこと・気になった所を連続評価する**（§3）: `python rt.py strip <S> 6-10 --box y0,y1,x0,x1`
   - 枠の位置は `view`（画素の目盛りつき）で決める
5. **直接所見を先に探す**（§4）。別断面で確かめる（`xref`）
6. **過剰読影を防ぐ定量チェック**（§5）: `roi`・`dist`
7. 図を3〜5枚作る（§6）
8. `out/report.json` を書き、`python rt.py check` が `OK` になるまで直して終わる

### 使う量を抑える（大事）
- 画像を Read するのは**合計40回程度まで**。同じ画像を2回開かない。一覧（montage）は既定の大きさのままで十分
- 拡大（strip・view）は、主訴の部位と所見のある所だけ。数値で決まることは `roi`・`dist` で出す
- 途中の考えは短く。最終的な文章は report.json に一度だけ書く

## 2. 左右と向き（毎回、最初に）
- DICOMの左右のタグは空のことが多い。`list` の「左右(名前から)」・X線の R/L マーカー・解剖で確かめる
  （膝・足関節は**腓骨側＝外側**、足は第1趾側＝内側、肩は肩甲棘など、左右で形の違う目印を使う）
- 画面の上下左右は `list` に出る（例: 画面左＝前方）。レポートの本文と図に毎回書く
- スライス番号と解剖の対応（例: 矢状断 #1＝内側、#18＝外側）を押さえ、別断面と相互に確かめる
- 反対側のシリーズがあれば左右比較する（図では `flip` で向きをそろえる）

## 3. 連続評価【最重要】
腱・靱帯・半月板・関節唇・軟骨・神経・骨端線など**つながっている構造**は:
- 対象を通る**全スライスを1枚も飛ばさず**、**同じ枠・同じ拡大率**で順に並べる（`strip`）
- どこで消えて、どこで戻るかを追う。**飛び飛びの数枚や1枚だけで判断しない**
- 薄いシリーズ（2mm以下）があればそれを主軸に。厚いシリーズは補助
- この並びはそのまま図にしてレポートに載せる（読み手が同じ追跡をやり直せる）

## 4. 直接所見と間接所見【最重要】
- 直接所見＝病変そのもの（断裂線、連続性の途絶、付着部の欠損、液体の介在、骨折線）
- 間接所見＝結果として起きた変化（骨髄浮腫、逸脱、萎縮・脂肪浸潤、変形）
- **直接所見を先に探す。間接所見が無いことを、否定の理由にしない**（あれば固まる、であって、なければ否定ではない）
- 数えやすい所見に判断を寄せない。位置が主訴・圧痛と一致するなら、まずその病変を疑う
- 「〜だろう」で片づけない（関節液が多い症例ほど「陥凹の液体だろう」で済ませやすい）

## 5. 過剰読影を防ぐ
- 脂肪抑制の不良: 撮像範囲の端では STIR・T2FS が偽に白くなる。同じ高さの皮下脂肪の信号を基準にし、骨髄が皮下脂肪と同程度なら抑制不良
- 骨髄の判定: STIRで白い所を T1 の同じ所と比べる。T1 で筋肉より明らかに明るければ赤色髄（造血髄）のことが多い（小児の足根骨では左右対称に出やすい）
- 骨内か関節内か: `xref` で別断面に写して確かめる
- 計測は STIR・T2 で「液体の信号に変わる所」を境界に。T1 では関節包・靱帯の深層も暗く、外縁を取り違える
- 数値は同じ撮像の中の相対値として書く（例: 筋肉の約2倍）。ただし、これらは**過剰読影の防止**のためで、否定の根拠には使わない

## 6. 図（`out/figN.json` → `python rt.py figure out/figN.json`）
```json
{"out": "fig2", "width": 1800, "rows": [
  [{"series": "s03", "k": 8, "box": [120, 380, 60, 360], "label": "矢状断 STIR #8",
    "marks": [{"type": "arrow", "from": [200, 120], "to": [235, 165], "color": "yellow"},
              {"type": "line", "from": [230, 150], "to": [242, 152], "label": "3 mm", "color": "cyan"},
              {"type": "circle", "center": [300, 200], "r": 25, "dashed": true, "color": "pink"},
              {"type": "rect", "box": [100, 140, 80, 130], "dashed": true},
              {"type": "text", "at": [90, 80], "text": "液", "color": "yellow"}]},
   {"series": "s04", "k": 8, "box": [120, 380, 60, 360], "label": "矢状断 T1 #8"}],
  [{"series": "s03", "k": 6, "box": [150, 300, 80, 230], "label": "#6", "scalebar_mm": 5}, "…（#7〜#10 も同じ枠で）"]
]}
```
- 座標はすべて**元の画像の画素**（row, col）。枠 `box` は [y0, y1, x0, x1]。`flip: true` で左右反転（反対側との比較に）
- スケールバー（既定 10 mm）と画面の向き（前・後・内・外など）は自動で入る。X線は向きが入らないので label に書く
- 1枚の図は1つの主張に絞る。連続評価の並び（同じ枠・同じ拡大率）を1枚は入れる
- 作ったら Read で確かめる（矢印が所見を指しているか）

## 7. `out/report.json` の形
```json
{
  "title_region": "右足関節",
  "headline": "カルテの一覧に出す一行（50字以内。例: 骨折・骨端線損傷なし。前方の関節液が圧痛部位と一致）",
  "summary": ["総括の段落（結論を先に。**強調**も可）", "…（2〜6段落）"],
  "sections": [
    {"heading": "1. 撮像内容と左右の確認", "blocks": [
      {"type": "series_table"},
      {"type": "p", "text": "左右と向き: …（どう確かめたか、画面のどちらが前・内か）"},
      {"type": "note", "text": "撮像されていないもの: …。「書いていない＝正常」ではありません。"}]},
    {"heading": "2. 主訴の部位の所見", "blocks": [
      {"type": "figure", "file": "figures/fig2.jpg", "caption": "図2 …（何を・どの断面・番号・向き・スケール）", "width": 100},
      {"type": "table", "columns": ["構造", "所見"], "widths": [25, 75], "rows": [["…", "…"]]},
      {"type": "p", "text": "…"}]},
    {"heading": "3. …", "blocks": ["…"]},
    {"heading": "4. 症状との関係と、確からしさの見積もり", "blocks": [{"type": "p", "text": "…"}, {"type": "estimates"}]},
    {"heading": "5. 提案と、再検討すべきサイン", "blocks": [{"type": "h3", "text": "圧痛点の特定"}, {"type": "list", "items": ["…"]}]},
    {"heading": "6. 読影ガイド — 自分で読む順番", "blocks": [{"type": "list", "ordered": true, "items": ["…"]}, {"type": "box", "title": "間違えやすいポイント", "text": "…"}]}
  ],
  "estimates": [{"condition": "考えられる状態", "percent": 35, "basis": "根拠（短く）"}],
  "references": ["著者. 題名. 雑誌. 年;巻(号):頁. doi:…"]
}
```
ブロックの種類: `p`（段落）・`h3`（小見出し）・`figure`・`table`・`list`・`box`（枠で囲む）・`note`（小さめの注記）・
`series_table`（撮像シリーズの表。プログラムがDICOMから作る）・`estimates`（見積もりの表。`estimates` から作る）。

### 書き方
- 読み手は柔道整復師。平易な日本語で、専門用語には短い説明をつける（例: 赤色髄（造血髄））
- 結論を先に。計測は mm と図で。図には向きと番号を書く
- **主訴の部位と撮像された部位が合わないときは、最優先で見出しにする**。撮像の不足（薄いスライスが無い、反対側が無い等）は具体的に書く
- 年齢・性別が問診とDICOMで食い違えば本文に書く
- 確からしさの見積もりは主な候補を合計100%前後で。**統計ではなく主観的な見積もり**であることは、プログラムが表の下に書く
- 「提案」には、圧痛点の確かめ方・誘発動作・追加の画像検査（超音波など）・早めに医師の再診を勧めるサインを入れる
- 文献は、著者・題名・雑誌・年・doi（または PMID）を**確かに知っているものだけ**。不確かなら書かない（作らない）
- 確定診断のように書かない。「〜を示す所見はありません」「〜と矛盾しません」「〜を最も考えます」のように書く
- 免責の文・氏名などの見出しは書かない（プログラムが入れる）
